# SWEEP - Structured Decluttering App
Sweep is a native Android app designed to help ADHD users manage their living spaces. The methodology utilizes hidden strengths of ADHD individuals by encouraging focus on single pattern goals with frequent and easily achieved goals.

This application was built as a Capstone project for the Bachelor of Science in Software Engineering program at Western Governor's University.

### Features
* **Guided Decluttering Routine** - A standard "sweep" plan walks users through a tried-and-true process that applies to any living space.
* **Unfinished Task Logging** - Automatically tracks outstanding clutter items.
* **Push Notifications** - Proactively reminds users of outstanding items and offers customization of notification intervals.
* **Task Resolution and Searchable History** - Users can revisit and resolve outstanding items at any time, and can search their history for item details.

### Tech Stack
* **Language:** Kotlin
* **UI Framework:** Jetpack Compose
* **Backend Database:** Firebase (Cloud Firestore)
* **Login Authentication:** Firebase Authentication
* **Build Tool:** Gradle
* **IDE:** Android Studio
